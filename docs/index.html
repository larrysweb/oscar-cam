Oscar Cam

Free, LAN-only camera grid for rooted LG webOS TVs. Arrange IP cameras in an adjustable grid; plays go2rtc, WebRTC, MJPEG and HLS streams. No account, no cloud, no telemetry.

Install on the TV

  1. Open Homebrew Channel on the TV.
  2. Go to Settings → Add repository.
  3. Enter exactly this repository URL (the manifest file itself, not just the site address):
    https://larrysweb.github.io/oscar-cam/manifest.json
  4. Install Oscar Cam from the repository.

Version 0.1.0. Source and full documentation: github.com/larrysweb/oscar-cam.
